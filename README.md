# ASD - Система управления заявками и задачами

Веб-приложение для управления заявками (тикетами), задачами, пользователями и другими аспектами организации.

## 📋 Описание

Проект представляет собой полноценную систему управления с поддержкой:
- Аутентификации и авторизации пользователей
- Ролевой модели (администратор, сотрудник, пользователь)
- Управления заявками (тикетами)
- Управления задачами
- Системы уведомлений
- Базы знаний (FAQ)
- Настроек системы

## 🚀 Технологии

- **Backend**: Node.js, Express.js
- **Frontend**: HTML, CSS, JavaScript, EJS
- **База данных**: SQLite3
- **Аутентификация**: bcrypt, express-session
- **Real-time**: Socket.IO
- **Безопасность**: CORS, CSRF protection, Rate limiting

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <project-directory>
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер:
```bash
npm start
```

Сервер будет доступен по адресу: `http://localhost:3000`

## 🔌 API Endpoints

### Аутентификация (`/api/auth/*`)
- Регистрация, вход, выход пользователей

### Администрирование (`/api/admin/*`)
- Управление пользователями
- Продвижение/удаление пользователей

### Заявки (`/api/tickets/*`)
- Создание, просмотр, управление заявками

### Задачи (`/api/tasks/*`)
- Управление задачами сотрудников

### Уведомления (`/api/notifications/*`)
- Система уведомлений пользователей

### FAQ (`/api/faq/*`)
- База знаний, часто задаваемые вопросы

### Настройки (`/api/settings/*`)
- Настройки системы

## 🔐 Роли пользователей

- **admin** - Полный доступ ко всем функциям системы
- **employee** - Доступ к панели сотрудника, управление задачами
- **user** - Базовый доступ, создание заявок

## ⚙️ Конфигурация

Переменные окружения (опционально):
- `PORT` - Порт сервера (по умолчанию 3000)
- `SESSION_SECRET` - Секретный ключ для сессий
- `NODE_ENV` - Режим работы (production/development)

## 🛡️ Безопасность

- Rate limiting для защиты от brute-force атак
- CSRF токены для защиты от межсайтовой подделки запросов
- Хеширование паролей с помощью bcrypt
- HTTP-only cookies для сессий
- CORS политика
